# Trademark Policy

Last updated: 2026-03-09

The source code is available under MIT. Trademark rights are separate from copyright licensing.

## Allowed

- You may fork, modify, and redistribute the code under the MIT License.
- You may describe compatibility with the project in factual terms.

## Not allowed without permission

- Using the project name, logos, or branding in a way that implies endorsement.
- Offering a hosted product using the same branding in a way that creates user confusion.
- Registering domains, social handles, or package names that are likely to be confused with this project brand.

## Clarification

- "Code is open" does not mean "brand is unrestricted."
- If you want to use project branding beyond fair descriptive use, request written permission from maintainers.
